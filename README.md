# Signal Harbor

Signal to foresight. Six modules take a business from the questions it wants answered to what is likely next, with an agent at every step and a named person signing every result.

This repo is in phase 0: structure, rules and tooling. Modules 1 (Intent Centre) and 2 (Baseline) are built next.
