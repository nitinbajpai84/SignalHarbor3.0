3. A redraft replaces an unsigned blueprint wholesale (people's edits to a draft blueprint are lost, as 2.0's own redraft from a draft baseline). A signed blueprint is kept as `blueprint.v<n>.json`.
4. Record ids from the SOW (`source:<id>`, `silver:<table>`) may differ from those B4's pipeline contracts later project (`source:<contract source>`); B3/B4 should name contracts by the SOW source id so they merge.
