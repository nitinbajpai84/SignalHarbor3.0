## Reuse check

- **Pipeline contracts**: there is no `sh_platform/build/pipelines*.py` in either repo. The contract shape lives in `sh_platform/build/contracts.py` (1-83: `derive`, `slug`, `NOT_YET`); imported, not copied. Each sheet row takes its source table (the contract `pattern` when the SOW source has no `sample_path`) and its rules (`"<measure>:<rule>"`, for the KPIs the table feeds) from `contracts.derive(plane)`. Runner (`sh_platform/build/runner.py`) not used here; B4 turns rows into contracts.
- **Span through the runtime**: the call shape is copied from `sh_platform/build/agents/span_suggest.py` `_ask` (205-218): `register_names`, `run_agent(rt.model, ToolRegistry(rt.gate), …, MODULE_ID, SPAN, …, read_tools.as_lines(context), …, recorder=rt.recorder)`. The empty registry follows `flow._ask` (55-67). The runtime comes from `sh_platform.build.agents.runtime.runtime_for_request`, so tests can use `build_model_factory` and `model_env`.
- **Workbook**: the look (navy header with white bold text, frozen header row, column widths, cells that look like formulas kept as text) is copied from 2.0 `modules/m2_baseline/domain/xlsx_export.py` (STYLES, BODY_TEXT, `_sheet`). It is written with openpyxl here instead of raw XML, because 1.0 has openpyxl.
- **Routes and refusals**: the Build-switch check is imported (`build.agents.routes._switched_on`). The architect check is `sh_platform.v1.seats.require_seat` (X3). The plane comes from `profile.api._plane`.
- **Screen**: page frame, table, chips and pills come from `ui/src/design`, laid out the same way as the B2 `ScanPage`. The download goes through the shared `downloadFile`.
- **New**: the row drafting rules (`draft_rows`), keeping a person's edit when Span drafts again, and the screen.

## What landed

- `sh_platform/v1/b3_mapping.py`: drafts, edits and reads the sheet, and builds the .xlsx.
- `sh_platform/v1/b3_routes.py`, with these routes:
  - `GET /api/v1/build/{iid}/mapping` returns `{sheet, fallback, message, drafted_at}`.
  - `POST …/mapping` asks Span to draft.
  - `PUT …/mapping/rows/{n}` edits a row. It accepts source_id, source_table, source_field, transformation, rule, test and status (`mapped` or `unclear`).
  - `GET /api/v1/build/{iid}/mapping.xlsx` downloads the sheet.
- `sh_platform/v1/b3.permissions.yaml`: GET for company_admin, analyst and sponsor; POST and PUT for company_admin and analyst. The handler checks the architect seat again.
- Records: `build/mapping/<iid>.json` follows the contract exactly. A sidecar `build/mapping/<iid>.meta.json` holds `{fallback, at, edited}`.
- Drafting rules:
  - There is one row per SOW catalogue field.
  - When the decision maker has agreed a scope, a table that feeds only KPIs outside the scope is left out.
  - A row is `unclear` when it has no source field, when its source is not in `sow.sources`, or when every KPI it feeds scanned `not`.
  - The rule column joins the contract rules with SOW governance rules whose `applies_to` names the table.
  - The test column follows the field's type.
- Span and the fallback: Span proposes the silver and gold transformations as JSON keyed `table.field`. When the model is off or the answer does not parse, the rule-based text stands (rename, parse a date, cast to a number, the KPI formula for gold), and the screen shows the labelled sentence.
- Refusals:
  - The SOW is not signed: 409.
  - Anyone but the architect drafts or edits: 403 `not_allowed`.
  - The Build centre is switched off: 403.
  - No SOW or no sheet: 404.
- Every draft raises the version by one. A row a person edited keeps their values when Span drafts again (hard rule 7).
- Room: `span` posts a `handover` to Flow and people with a `mapping` reference. The import is guarded, so a broken room never breaks the sheet.
- `ui/src/v1/b3/routes.tsx` (`build/:iid/mapping`), `api.ts`, `MappingPage.tsx`:
  - The sheet with chips that filter by layer and by status.
  - An edit form per row, for the architect only.
  - "Ask Span to draft (again)" and "Download .xlsx".
  - States: loading, empty, error and refused.
- Tests:
  - `tests/v1/test_b3.py`, 3 passed: draft, edit, redraft keeps the edit, download; Span with a stub model; the sponsor refused and an unsigned SOW refused.
  - `ui/src/v1/b3/MappingPage.test.tsx`, 2 passed.
  - `tsc --noEmit` is clean.
