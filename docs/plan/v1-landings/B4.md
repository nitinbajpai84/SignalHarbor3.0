## Open questions
- Staged files `landing/_b4_v1_<source>.csv` sit in the landing root. B2's scan of `data/<company>/landing` should skip names starting `_b4_`.
- Mapping `target_table` for silver rows is not honoured: the runner's silver table is always `silver.v1_<source>`. Gold rows build `gold.<target_table>` in the one gold shape (period, value), first measure only (runner's limit). If B3 names a gold table the same as an existing demo mart (`k01`...), its periods are overwritten by this load. C1 should agree the gold names with B3.
- Which mapping column holds the check: B4 reads both `test` and `rule` and runs those that are a not-empty, unique or range check; others are listed as "could not run". Uniqueness is checked on the row's own `source_field` (the contract has no key list).
- Arrival times: contracts use WD5 expected, WD8 deadline (month-end files), marked `guessed`; the SOW has no field for when a source arrives.
- An XLSX gives the sheet named like `source_table`, else its first sheet.
