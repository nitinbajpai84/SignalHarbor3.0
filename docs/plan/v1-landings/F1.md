## How to test by hand
1. Sign in as Leela Raman (analyst). You need an intent with a mapping sheet (Span's conversation or `POST /api/v1/build/<iid>/mapping`) and ideally one load run.
2. Open `/centre/build/<iid>/engineer`. Flow's first message says what it has read and how many open points there are, and asks about the first. The Open points tab lists them.
3. Answer "yes": the row is marked mapped on the mapping sheet (`/centre/build/<iid>/mapping`) and Flow asks the next. Answer with words ("use issuer_name, trimmed"): the transformation is rewritten. Paste a `select ... from silver."v1_<source>" ...`: the row shows the SQL as the engineer's.
4. Say "I am not sure": the point stays open. On the Real engineer tab, flag it with a note, then Download as Markdown.
5. Pipeline tab: Run the load; failed checks become new open points after the page reloads.
6. Answer the last point: Flow says it has told the ops manager; the room (`/centre/intent/<iid>/room`) shows Flow's hand-over.
7. Sign in as Priya Nair (sponsor): the page reads with no composer; a POST answers 403.
