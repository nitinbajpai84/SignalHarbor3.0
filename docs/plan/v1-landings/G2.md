## How to test by hand
1. Sign in as Arjun Mehta (decision maker), open a project whose build pack is signed (stage Built). The right column shows "Go live". Press it with an open comment on any artefact: a plain sentence says how many are open. Answer and resolve them, press again: stage chip turns Live.
2. Sign in as Dev Sharma or an analyst who is not raiser/sponsor on that project and press Go live on a built project: "Only X or Y can take this project live."
3. As Leela Raman (ops seat) open the project, chip "Run book": Flow's draft is there (or press "Ask Flow to draft the run book"). Comment on a line addressed to the builder; "Sign the run book" is refused until it is resolved. Edit, Save, Sign.
4. Ops page (`/centre/build/ops`): "Live projects and tickets" card shows the daily state and the ticket form. There is no hand-over button on the engineer or ops page.
