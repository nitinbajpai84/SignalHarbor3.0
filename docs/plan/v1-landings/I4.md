## Rules decided
- **Signing is refused while any unclear point is open.** The screen names how many and asks for them to be settled first.
- **Sign writes, in order:**
  1. The I5 scan (a no-op when it is missing).
  2. sow.json is frozen: state `signed` and `signature {name, role, at}`.
  3. The glossary: each KPI with a definition becomes a term. The definition carries the formula, and the KPI code is an alias.
  4. The catalogue: a module 2 baseline whose id is `md5("v1-sow:" + iid)`. Deriving the id means sow.json needs no new field. The sources, tables and fields go in, then the baseline is set to `signed`.
  5. A room post `north → span`, kind `handover`, refs `[{kind: sow}]`.
- **If the glossary or catalogue write fails, the signature still stands.** The answer's `written` block reports the error instead.
- **Re-signing after C2 reopens the record** (orchestrator ruling):
  - Every signature is also appended to a new `signatures` list on the record as `{name, role, at, version}`. C2 clears `signature`, so the old signed version is kept there.
  - Glossary terms already written stay as they are, through add_term's reuse or propose.
  - The catalogue baseline is opened to `review` only for the length of the write. Any row whose cells already match a row is left alone. A new row is added, and a *changed* row is added as a new row, so the earlier signed row is never edited. The baseline then goes back to `signed`.
- **Catalogue mapping:**
  - **Links to KPIs**: the m2 tables and fields tabs can only link to KPIs held in the baseline's kpis.json, which 1.0 does not fill. So the KPIs each table feeds are written as text in the row's Notes ("Feeds KPIs: …").
  - **Tables with no single source**: silver and gold tables that come from several sources hang off one source row named "Statement of work: <title>".
- **Send back**: a person turn is added to `thread.json` in the contract's shape ("Sent back from the statement of work: …") and the thread is set back to `open`. A room `question` goes to North.
- **Downloads**: Markdown always. Word only when python-docx imports. It is **not installed** on this box, so the screen shows only the Markdown button and `format=docx` answers 404 with a plain sentence.
