## What landed

- `sh_platform/v1/catalogue_scan.py`: `scan(plane, iid, rt=None) -> dict`. Collects files from `thread.json` turns and from SOW sources with a `sample_path`; CSV/XLSX become `kind: file` sources (fields with name, type, example, meaning) plus one landing catalogue row per file or sheet; anything else becomes a `kind: document` source with `read` (what was read, by whom). Then fills empty field meanings from document definitions, empty source owners from document owner lines, `feeds_kpis` from `kpis[].source_ids`, and adds an `unclear` entry when two documents define the same term differently. Never overwrites a filled cell (rule 7); a source the SOW already lists keeps its id. Refuses (`catalogue_scan.Refused`) when there is no SOW or it is signed. Marks the graph dirty. Returns `{sources, tables, unclear_added, read: [{file, kind, by}], skipped: [{file, why}], sow}`.
- `sh_platform/v1/i5_docs.py`: `read_document(rt, file, text)`. With a model: only the lines carrying a cue (capped at 4,000 characters) leave, wrapped as untrusted text, as module `m1_intent`, agent North. With the model off, unreachable, or a reply the number guard changed: `by_rules` (headings, tables with a Meaning/Owner/System column, "X means", "X is the", "term (ABBR):", "term: meaning" list items, "owner:" lines, "system:"/"source:" lines, "in the X system", rule words) and `read.by` says so in plain words.
- `sh_platform/v1/i5_graph.py`: `add_sow_nodes(g, plane, people)`. For each 1.0 `intents/*/sow.json`: `intent:<iid>` -solves-> `problem:sow-<iid>` (the goal line) -uses-> `source:<id>` -feeds-> `measure:<code>`; `source` -feeds-> `table:<name>` -feeds-> `measure`; a document source -defines-> the KPI it defines (quote in the provenance); source -owned_by-> person. Adds `Intent`/`Table` node types, the `intent` room and the `solves`/`feeds`/`defines` edges, and widens `uses`.
- `tests/v1/test_i5.py` and `tests/v1/fixtures/i5/` (one CSV, two Markdown documents; the two-sheet XLSX is built in the test).
