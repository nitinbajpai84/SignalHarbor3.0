## Open questions

- Internal and Restricted behave the same mechanically (lock, preview, request, owner names people); they differ in the default and the preview (Restricted by personal data names kinds only). Per-project teams arrive with G1; until then "named people" are grants.
- No screen yet for the owner to revoke a grant, name people, change sensitivity or topic on an existing item, or for a company_admin to reassign; the routes exist (`PUT /library/{id}`, `/grants`, `DELETE /grants/{account}`, `/owner`, `GET /people`).
- The file name (digits and emails removed) goes to the fast model for an unclear file; a file named after a person would carry that name. Column names and the first heading go with it. Tokenising names there needs the name vault from the gateway.
- "Away" owners are not detected (only left or disabled accounts). Seeded company items have no owner and are Open.
- The topic list is L3's folders plus Finance, Reporting, General ledger and Pictures; the library folders route classifies items stored before K1 by rules at read time without storing it (L3's one-time batch will store it).
- `Looks like ...` message uses the lower-cased topic; fine for the demo, wording to be reviewed.
