Retry up: a reply that is empty, not the asked JSON (`want_json`), or would have a figure rewritten by the reply guard (checked when the context is a dict with `facts`) is asked once more on the next tier. A provider failure (`transport_failed`, `no_credential`, or no key for the tier) goes to the tier's `_ALT` model (Real use, from `.env`), then the next tier up; Testing has no alternates, so the free Google tier falls straight to the specialist. A gateway refusal (vault name, suppressed figure) is never retried. `SH_ROUTER=off` (process environment) returns the plain settings client: the specialist from `.env`.

## model_costs.jsonl (company plane, `context/model_costs.jsonl`, one line per attempt)
```json
{"at": "2026-10-08T09:00:00+00:00", "agent": "north", "task": "reply", "tier": "fast", "model": "gemini-2.5-flash-lite",
 "tokens_in": 1520, "tokens_out": 210, "retried": false, "intent_id": "i-123",
 "estimated": false, "mode": "testing", "step": "first", "ok": "ok"}
```
The first nine keys are the card's. Added (Open question 2): `estimated` (characters/4 when the provider gave no usage), `mode`, `step` (first | alt | fallback | retry_up), `ok` (ok | not_json | empty | number_guard | transport_failed | no_credential | no_key). `GET /api/v1/router/costs?iid=` returns `{intent_id, calls, tokens, by_tier, fast_share, estimated, rows (last 50)}`.
