## What landed
- `sh_platform/v1/room.py`: `post(plane, iid, by, kind, text, to=None, refs=None, *, name=None) -> post` and `read(plane, iid) -> {"intent_id", "posts"}`. Validates `by`, `kind`, `to` (agent keys or `"people"`), `refs` kinds; iid is `[A-Za-z0-9_-]`. Pass `name=` for a person. After any non-Nira post it calls Nira (guarded: Nira failing never breaks the caller).
- `sh_platform/v1/x1_nira.py`: `facts` (reads thread, sow, scan, mapping, runs, loaded, room posts), `by_rules` (fixed order thread → sow → design → scan → mapping → load → loaded → consume), `ask_model` (through the runtime; accepted only when it names the stage the records support), `after_post` (on a change of stage/waiting_on: writes `intents/<iid>/room_state.json` `{stage, waiting_on, since}` and posts one `nudge`; stays quiet otherwise), `state`.
- `sh_platform/v1/x1_routes.py`: `GET /api/v1/intents/{iid}/room` (record + `state`), `POST /api/v1/intents/{iid}/room` `{text, to}` (a person answers; 403 unless company_admin, sponsor or analyst; 404 for an intent folder that does not exist).
- `sh_platform/v1/x1.permissions.yaml`: GET for all six company roles, POST for company_admin, sponsor, analyst.
- `ui/src/v1/room/`: `routes.tsx` (`intent/:iid/room`), `RoomPage.tsx`, `RoomStrip.tsx` (`<RoomStrip iid=… />`: last post + waiting line, links to the room), `api.ts`, `room.test.tsx`.
- Tests: `tests/v1/test_x1.py` (3 pass), `ui/src/v1/room/room.test.tsx` (3 pass); `tsc --noEmit` clean.

## How other cards use it
```python
try:
    from sh_platform.v1 import room
    room.post(plane, iid, "span", "handover", "The scan is ready for you to agree.", to=["people"], refs=[{"kind": "scan", "id": iid}])
except Exception:  # a missing room never breaks a card
    pass
```
Nira's "design done" signal is any Span post or the scan file; "load done" is a Flow post with a `run` ref or a run in `warehouse/runs.json` carrying `intent_id`. So B1 should post a Span hand-over after the design, and B4 should post with `refs=[{"kind": "run", "id": run_id}]`.
