# E0c1 Landing and census backend

## What changed
Files arrive by upload or by the inbox folder. The original is kept untouched, a record says who sent it and what state it is in, and the same bytes are never registered twice.

- `landing/inbox/[source_code/]<file>`: drop zone (scanned, left in place). A sub-folder name becomes the source code; loose files are source `inbox`.
- `landing/originals/<sha256>__<name>`: the untouched copy. `landing/records/<file_id>.json`: {file_id, sha256, name, size, received_at, sender, owner, source_code, sensitivity, state, note, profile, last_load, last_load_at}.
- States: new, profiled, waiting_for_mapping, loaded, rejected_totals, quarantined. A non-spreadsheet file (not .xlsx/.xlsm/.csv) or an unreadable one is quarantined and kept as received.
- Load results from E0c2 map to states by `status`: loaded, waiting_for_mapping (also `layout_changed`), rejected_totals.

## Files
`sh_platform/v1/e0c_landing.py`, `e0c_routes.py`, `e0c.permissions.yaml`, `tests/v1/test_e0c1.py`.

Routes (all `/api/v1/intake`): `GET /files` (scans inbox first; returns files, by_source, states, inbox_note), `POST /scan`, `POST /upload` (multipart: `file`, optional `source_code`, `sensitivity`; returns record + `duplicate`), `GET /files/{id}`, `POST /files/{id}/profile` {sheet?}, `POST /files/{id}/load`. Reads: any signed-in company member. Upload, scan, profile, load: data engineer / ops manager seat.

## How to test on the demo
1. `SH_MODEL_PROVIDER=off python -m pytest tests/v1/test_e0c1.py -q` (7 tests).
2. Copy a workbook from `tests/v1/fixtures/e0d/workbooks/` into `data/<company>/landing/inbox/administrator/`, call `GET /api/v1/intake/files`: it appears as `new` under source `administrator`.
3. `POST /api/v1/intake/files/{id}/profile` (needs E0b2), then `/load` (needs E0c2).

## Known limits
- Multipart is parsed with the standard library because `python-multipart` is not installed (no package to add). Limit 25 MB a file.
- The 60 s poll starts lazily on the first intake request per company and stops at process end (daemon thread); `L.stop_polls()` for tests.
- `profile_sheet` and `load` are imported lazily; if the module is missing the route says "not ready" (503) and logs a warning.
- Profile uses `profile_sheet(path, sheet)` with the original's path; a file with several sheets is profiled one sheet per call.

## Wiring for the orchestrator
- Router auto-installs per the card pattern (`e0c_routes.router`). Optional: call `e0c_landing.stop_polls()` on app shutdown.
- Packages: none.
- Assumption E0c2 relies on: `e0c_landing.get(plane, file_id)` returns the record, `e0c_landing.original_path(plane, rec)` the untouched file.
