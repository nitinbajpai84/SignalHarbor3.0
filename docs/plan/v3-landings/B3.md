# B3 landing: architecture diagram for a plan

Files: `sh_platform/v1/b6_diagram.py`, `b6_diagram_routes.py`, `b6_diagram.permissions.yaml`; `ui/src/v1/b6diagram/{layout.ts,api.ts,PlanDiagram.tsx,diagram.test.tsx}`; `tests/v1/test_b6_diagram.py`.

Route: `GET /api/v1/build/p/{pid}/diagram` returns `{project_id, version, state, layers, nodes, edges}` from the newest `build/<pid>/plan-v<n>.json` (404 with a plain message when none).

Wiring for the orchestrator / B1: `import PlanDiagram from "../b6diagram/PlanDiagram"` and render `<PlanDiagram projectId={pid} />` in step 4 (Diagram). No route of its own.
- "New" = bronze and gold tables, any table with `new: true`, and silver not in the catalogue (`e0a_catalogue.layer_of(plane, name)`; until D1 lands every silver table counts as existing).
- Consumers box appears only when the plan has a gold table.
- Exports: SVG file and Archify-style JSON spec (client side, buttons on the component).
