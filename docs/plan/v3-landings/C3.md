## Wiring for the orchestrator
- E5a (`e5_pulse.py`) has no plug-in point for outside sources, so `cx_share.notify` inserts `pulse_items` rows itself (role `*`, kind `dashboard`, link `/centre/consume/d/<id>`). `e5_pulse.generate` never touches them (it only rewords cards it made itself); `items` shows them.
- C1 (`cx_routes.py`) calls `cx_share.notify(plane, pid, did, "shared")` when the audience is saved, and B4/C1 call `notify(plane, pid, did, "refreshed", token=<run_id>, tiles_changed=n)` after a refresh. `token` makes a repeat for the same event a no-op.
- Cards count toward E5a's cap of seven open cards per person.
- The Action UI shows `action_type: open_dashboard` as a normal card; A1 may map it to its link.
