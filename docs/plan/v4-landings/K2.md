# K2 landing: Office view in Consume (UC1, UC6 view)

Files (all new, nothing existing edited, so no backups were needed): `sh_platform/v1/k4_office.py`, `k4_routes.py`, `k4.permissions.yaml`, `ui/src/v1/k4/{api.ts, OfficePage.tsx, routes.tsx, k4.test.tsx, office.fixture.json}`, `tests/v1/test_k4.py`.

## Routes (all GET, read-only, filtered by E1d, fail closed)
- `/api/v1/office/holdings?currency=&as_of=` entities > portfolios > lines `{name, value, currency, native, status, source, where}`; totals only where everything under them is visible and convertible. Status word: official, revised, estimated, unverified, or **stale** (older than 90 days).
- `/api/v1/office/issued?currency=` latest issued report from E1c/E5b: lines as issued beside known now, banner, `brief_link` (`/centre/consume/brief/<id>`).
- `/api/v1/office/nav-bridge?currency=&as_of=` per portfolio: investment total, administrator NAV, difference, and four parts that add up exactly: revisions (recorded after the NAV was struck), timing (valuations dated after the NAV date), exchange rates, unexplained. Each part carries `evidence` rows (statement page and line, NAV record, fixing used).
- `/api/v1/office/liquidity?currency=&as_of=` passes through K4's `k6_liquidity.forecast(plane, as_of, viewer=, currency=)` (cash, calls and distributions due overdue/30/60/90, cash after calls, uncalled, unconfirmed calls). If K4 is not installed it answers `available: false` with a plain message.
UI routes: `/centre/consume/office` and `/centre/consume/brief/:reportVersionId` (the existing E5 BriefPage, so the brief is reachable inside the Consume part of the new shell; the old `/centre/brief/...` still works).

## How to see it (demo company)
1. Sign in as the CIO or an analyst, open `/centre/consume/office`.
2. Holdings: each line has a status word and source; "Where is this from?" shows the statement page and a link to open it. Switch USD/SGD (needs a signed `fx_fixing` rule and a rate; otherwise it says why).
3. "Issued versus known now": Open the CIO Brief link.
4. Investment total against administrator NAV: open "Where is this from?" on each part.
5. Liquidity: shows cash, calls due and the "Not confirmed yet" list once card K4 data exists.

## Known limits
- NAV bridge default `as_of` is today; the NAV used is the latest per portfolio on or before it. The bridge needs a signed `fx_fixing` rule and a rate on both dates when holdings are in another currency than the report currency; otherwise it says which rate is missing.
- A SGD switch shows "Not available yet" for a line that cannot be converted (never zero).
- "Where is this from?" on the Holdings section shows the one source row behind the value, not the full revision chain (the brief's "Why did this move?" has the chain).
