# V5W-1 Assignments and the Action landing

## What was built
- `sh_platform/v1/p2_assign.py`: assignment model. Events (assign, handover, done, withdraw) kept in `assignments/log.jsonl` of the company space, append-only; open state is folded from them (a later assignment of a step replaces the earlier one). The person assigned joins the project team and becomes its builder; the owner stays the owner. Only the project owner or a company admin may assign (`g1_access.can_manage`); the assignee finishes their own part; the assigner or an admin withdraws.
- Today: registered an `e5_pulse` card source. Assignee gets a "Needs me" card (Assigned to you); the project owner gets a "Worth a look" card. No model, words copied from the record.
- `sh_platform/v1/p2_routes.py` + `p2.permissions.yaml` (default deny, declared per route). Auto-installed by `sh_platform/v1/__init__.install`, so no `app.py` line is needed.
- Landing data `GET /api/v1/action/landing`: needs_me, assigned_to_me, assigned_by_me, waiting_approval (dashboards submitted, build plans proposed, intents ready for the sponsor), worth_a_look, and counts.
- UI `ui/src/v1/a5/`: `ActionLanding.tsx` (greeting, Assigned to me, Waiting for my approval, Waiting on others) wraps the existing Today (`TodayTrail` / e5 `TodayPage`, so Needs me, Worth a look, Take case, Where is this from?, Not for me all stay) inside `ActionCentre.tsx` (Today tab). `AssignPage.tsx` is the A5/B4 form on its own route. `ui/src/v1/p2/api.ts` is the typed client.
- Compatible with Package 2's dialog (`ui/src/v1/b9/AssignDialog.tsx`): server accepts `note` as well as `message`, `handover: true` on `/assign`, a person by id or name, returns `assignments` (a row per step) from `GET .../assignments`, and serves `GET .../assign/candidates`. Build's dialog works without edits.

## How to see it
Sign in as a project owner, open `/centre/action/assign/<project id>` (or `?mode=handover`), assign to a colleague; sign in as that colleague: `/centre/action` shows Assigned to me.

## Mount lines (integration step)
- Backend: none. `p2_routes.py` is picked up by `sh_platform/v1/__init__.install` and `p2.permissions.yaml` by `extra_permission_files()`.
- Router/nav: none. `action/assign/:pid` is in `ui/src/v1/a5/routes.tsx` (my folder); `ui/src/v1/index.tsx` globs it.
- Build project page (Package 2) can link to `/centre/action/assign/<pid>` and `/centre/action/assign/<pid>?mode=handover` if it does not use its own dialog.
