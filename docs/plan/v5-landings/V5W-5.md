# V5W-5 Consume reading room (E1 to E7, ConsumeMorningNote)

## Built
- **One page, six tabs, Lumen as one side panel** (`ui/src/v1/k10/ConsumeRoom.tsx`): Morning Note, Daily P&L and NAV, Market signals, Reports, Dashboards (published only), Shared with you (with its count). USD/SGD chips on the tabs that show money. `/centre/consume` now renders it (`cxui/ProjectList.tsx` is a three-line wrapper), so **no router edit is needed**. "Your projects" and the project picker are gone from Consume (the project page `consume/p/:projectId` and the read-only dashboard view are unchanged).
- **Backend** `sh_platform/v1/k10_note.py`, `k10_routes.py`, `k10.permissions.yaml`. Nothing is worked out by a model; every function reads an existing one and keeps its access filter (k9_daily, k4_office, k5_managers, k7_benchmark, e3_calc, e1_reports, e5_brief, e4_cases). Single-segment paths on purpose, because card C1 owns `/api/v1/consume/{iid}/{code}`.
  - `GET /api/v1/consume/note` Morning Note: headline and summary worded from the figures, four figures (value known now, liquid book return against the benchmark, calls due in 30 days with confirmed and not-yet split, limits over), what moved it, also on watch, needs you (open cases, material first), market lines, reports, comment target. Every figure carries a `trail_id` and a "where is this from" text.
  - `GET /api/v1/consume/pnl` issued against known now (both currencies, the signed fixing), liquid book day / month / year to date (day says "Not available yet: it waits for the daily price file"), administrator against our view per portfolio with the named cause, by entity. The existing six-card Key numbers band sits at the foot of this tab (nothing dropped).
  - `GET /api/v1/consume/signals?period=month|ytd|inception` index and FX moves from `market_observations` (level start to end, change, direction, source and date, all marked outside), the private markets proxy and the 60/40 sleeve taken from the signed benchmark's own components, portfolios against their benchmarks (alpha in points), funds against their index, a short read worded from the figures, manager news from the library (newsletters, letters, questionnaires as written, with source and date, outside material). A market with no feed ("Regional equity (Asia ex-Japan)") and a fund return with no confirmed statements show "Not available yet".
  - `GET /api/v1/consume/league?rank=alpha|value` the fund league: rank, fund and manager, value, status word (Official, Revised, Estimated, Unverified, Stale, Late), the reason under each, the four counts, the "cannot be ranked fairly" note.
  - `GET /api/v1/consume/reports` the library (warehouse reports with every version, signer and date; Manager scorecard, Liquidity ladder, Exposure and limits as live views linking to their pages). `GET /api/v1/consume/reports/{version_id}/pdf` a signed version as a PDF (reportlab): as issued beside known now, the open-case banner, signer, cutoff; only the lines the person may see; an unsigned version is refused (409) in plain words.
  - `GET /api/v1/consume/email-note` the daily email as `{subject, html, text}`. **`k10_note.render_email(note, base_url="")` is the template package 4 renders**: pure, escapes every value, inline styles only, no pictures or scripts. Package 4 calls `k10_note.morning_note(plane, viewer, currency, as_of)` for the dict and then `render_email`.
- **UI** `ui/src/v1/k10/`: `MorningNote`, `PnlNav`, `MarketSignals`, `FundLeague`, `ReportsLibrary` (PDF through the existing `DownloadButton`), `EmailPreview` (sandboxed frame), `ConsumeRoom` (also the Dashboards and Shared with you tabs, moved from the old ProjectList), `format.tsx`, `api.ts`, `routes.tsx`.
- **Morning Note sections from Delivery**: it asks package 4's `GET /api/v1/consume/morning-note/delivery-lines` and shows each approved Morning Note channel as a section; with no such route it shows nothing extra.

1. **None for the app or the router.** `k10_routes.py` and `k10.permissions.yaml` are picked up by the `v1` glob (like k9); `ui/src/v1/k10/routes.tsx` by the `v1` route glob; `consume` itself by `cxui/routes.tsx`.
2. `requirements.txt`: add `reportlab` (PDF export). Without it the PDF button says "A PDF cannot be made on this server" and everything else works. It is in the venv used here.
3. Shell (package 2), optional: the Consume bar item already points at `/centre/consume`. If the shell wants direct links, they are the six tab paths above.
4. Package 4: `from sh_platform.v1 import k10_note` then `note = k10_note.morning_note(plane, viewer, "USD", None)` and `k10_note.render_email(note, base_url)` for the 07:00 email; the preview is `/centre/consume/email`.

## Open items
- **Fund return and alpha for a single fund are not worked out.** They need confirmed statements at both month ends plus that fund's calls and distributions; until a rule exists they read "Not available yet" and the league ranks by trust, then value. The code path for alpha is in place (`FundRow.alpha`) but nothing feeds it. Which index fits a fund is read from the instrument's asset class and name (`_index_for`); a signed fund-to-index mapping would replace it.
- **The design's "Needs you today" is the open cases, not "mine".** Cases carry no assignee in the seeded data, so the list is the material open cases for everyone who may see them. Once package 1 defines "waiting for me", filter `_cases` by it.
- **Comments on the note** use the existing `brief_line` thread (`company/morning-note-<date>`), so a mention's link opens the CIO Brief. A dedicated thread kind needs a change in `n2_comments.py` (not mine).
- Not built from the designs: PowerPoint export on the Reports cards (the card asked for PDF), the "Delivery settings" button and the Slack thread preview E7 (Delivery is a Build step now; package 4 owns the channels), "Needs my signature" for the viewer only (the filter is "Awaiting signature"; no report is waiting in the seed), the 07:00 time in the kicker (no run time is recorded).
- The portfolio comparison picks its yardsticks by name: a portfolio with "liquid" in its name is set against the signed blend and its 60/40 sleeve, every other portfolio against the private markets proxy. A portfolio-to-benchmark link in the warehouse would replace this (same note as k9_daily).
- Not run: the full backend suite, screenshots against the artboards (no vite build in this package; for the integration step), a live Lumen check.
- Speed: the Morning Note, signals and league each read the warehouse several times (k9_daily, inbox, cases). Fine for the demo size; cache per request if it grows.
