# V5W-6 The company map as one living ontology

## Built
- `sh_platform/v1/k3_onto.py`: one graph from existing records. Reuses `k3_map` (flow, definitions, health), `p1_project`, `mem_graph` (decisions), `e4_cases`, `cx_dash` (reports). Eleven node types, six relations (owns, feeds, defined by, decided in, raised from, built by), five lenses, growth steps per project, verified vs in progress, review queue. Verification (who, when) is kept in `graph/verified.json` of the company plane.
- Rule: an item that belongs to a project is in progress until the project is live AND the head of data (company_admin) admits it. Sources, raw tables, people, agents and cases are baseline (verified). A link is solid only when both ends are verified.
- `k3_routes.py` (already mounted) gains: GET `/api/v1/centre-map/ontology`, GET `/review` (data team), POST `/review/approve` and `/review/reject` (company_admin only). Declared in `k3.permissions.yaml`.
- UI in `ui/src/v1/k3/`: `OntologyPage` (find, lenses, what to show, state, one project at a time, growth timeline with replay, list view, node card), `OntoGraph` (own layered SVG layout in `onto.ts`; no new dependency), `NodeCard`, `ReviewQueue`. The four Build step icons come from `ui/src/v1/b9/StepIcons.tsx`.

## See it
`/centre/map/company` (?lens=flow|process|definitions|people|health, ?project=<id> for growth, ?list=1, ?focus=<node id>) and `/centre/map/review`. The Map page has two new chips, "Whole company" and "Review queue". The old "Company map" chip and all five Map tabs are unchanged.

- **Designs:** F1 matches: the title, the subline about solid and dashed, "Waiting for you · Review N items", find, the "What to show" counts, the state filter, one project at a time, layered columns from people through to outputs with meaning in a band beneath, and the node card. - **Nothing dropped:** the Map keeps all five tabs and the "Company map" chip, and the two new chips are additions.
