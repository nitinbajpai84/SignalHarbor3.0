# Acceptable use policy

Status: draft (W7). Applies to everyone with access to Signal Harbor systems or client data.

1. Use company systems only for Signal Harbor work and for the clients you are assigned.
2. One person per account; never share passwords; use a password manager and your authenticator app.
3. Keep devices locked, disk-encrypted and patched; report a lost device at once (`incident-response-plan.md`).
4. Never put real client data in tests, demos, chats, issue trackers or model prompts outside the product; use synthetic data.
5. Never put secrets (keys, passwords, tokens) in the repository; the secret scan flags them and you must rotate any that slip.
6. Do not bypass controls: the access guard, the egress vault, the audit log, or the pre-merge scans.
7. Export client data only when the client or a signed decision calls for it; every export is logged.
8. Report suspected incidents and weaknesses; there is no penalty for a good-faith report.
9. Breaking these rules can end access and, for a contractor or employee, the engagement.
