# Colour means one thing, everywhere

A person should never need a guide: the colour says what kind of thing it is.

| Token | Colour | Means | Use it for | Never for |
|---|---|---|---|---|
| `--act` | navy #1B3A5C | **You can do this** | primary buttons, links, the active tab, focus rings, a person's own messages | status |
| `--needs` | amber #B7791F | **Waiting for a person** | decisions and questions open, "needs you" counts, files waiting, the left edge of an Action card | finished things |
| `--done` | green #1E7B4F | **Finished and checked** | signed, loaded, matched, live, a stage reached, a passed test | buttons, decoration |
| `--problem` | red #B23B32 | **Something is wrong** | a mismatch, a failed step, a late file, Discard | warnings that only need attention (use amber) |
| `--harbor` | brass #B08D57 | **Harbor did or said this** | Harbor's avatar, the mic, "Harbor is doing…", lines Harbor drafted ("suggested"), the answer's highlight | person actions |
| `--info` | slate #5A6878 | **Just information** | secondary text, labels, neutral counts, not-yet-reached stages | anything that needs action |
| `--ink` / `--paper` / `--card` / `--line` | navy ink, light grey, white, slate hairline | the page itself | text, page, cards, borders | meaning |

Soft variants (`--needs-soft`, `--done-soft` …) are the tinted backgrounds of the same meaning (pills, rows, cards).
Charts: the asked-about item in brass (Harbor's answer), the rest navy then slate. One accent per screen.
