## 3. Ranked fix list

1. Answer routing and row selection (class c, 6 cases). Fixes morning-networth-note, uc-008, uc-017, uc-029, uc-031 and uc7. Code area: `consume.answer-question` in the answer path (`sh_platform/v1/v3_figures.py`, answer section). Changes: (i) a figure bound to the question's own words beats word overlap ("report" to TWR, "worth" to change); (ii) filter rows by the entity, manager or as-at named in the question; (iii) for "release / which" questions return every state of the batch, not one state.

2. Bind figures to existing recipes (class a, 5 cases). Fixes uc-015, uc-023, uc-024, uc-028, uc-032, and uc-001's "Allocation drift" (6 with uc-001). Code area: `v3_recipes.match` and `bind` (`sh_platform/v1/v3_recipes.py`), plus the recipe `names` lists in `packs/family_office/1/recipes/`. Add names: `allowance_due` ("owed to family members"), `report_tie_out` / `statement_vs_admin` ("agree with the administrator"), `trace_coverage` ("total items traced", "missing trace count"), `intercompany_balance` ("lends to", "intercompany loan"), `drift_vs_target` ("policy band", "outside its band"). The binder should also use the question text, not only the figure name.

3. Recipe SQL defects (class f, 3 cases). Fixes uc-007 (shadow commitment rows; 58.6M vs 14.6M), uc2-recon-break-desk (`cash_break` is cumulative and repeats snapshots on other days), and the morning note's duplicate cash rows in `net_worth`. Code area: `packs/family_office/1/recipes/cash.yaml` (`called_to_date`, `commitments_by_fund`, `cash_break`) and the net-worth recipe. Each needs a test on the office data before it is trusted.

4. Decision1 loop (class e, 2 cases: uc-013, uc-026). The "reported last period" gap is re-asked after every confirm and nothing answers it. Fix in two places: the runner must answer open questions or say "use the usual practice" (test side); and Span should accept "use the usual practice" as the answer for a template field that has no prior report, with a loop guard after N identical gaps (`sh_platform/v1/t1_seeds.py:77` and the decision1 handler). Also check whether "Master-data owner assignment" needs a recipe.

5. Empty bound figures and missing routes (class b and f, 3 cases). uc5: `single_name_breach` has no table, so the breach list is never answered (`packs/family_office/1/recipes/report.yaml:206`, Span design). uc-016: schema-drift and renamed-column questions have no route ("not a question about a figure of the brief"); the answer should cite the Flow mapping. uc3: the day count must exclude Singapore public holidays, and the answer must cite the table row. Also uc-001: column names derived from KPI labels must be slugified before the check (`sh_platform/v1/b10_design.py:65`, `sh_platform/v1/e0a_catalogue.py:187`).
