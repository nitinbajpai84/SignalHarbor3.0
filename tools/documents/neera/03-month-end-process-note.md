# Month-end process note

Owner: Kiran Iyer (Operations Lead). Last updated 3 August 2026.

1. Working day 1: Kiran downloads the custodian position and transaction files from the Northgate Custody portal and the Pier Bank cash statement. Files are saved to the shared landing folder, named with the month, for example positions_2026-07.csv.
2. Working day 2: Rohan Das (Treasury Officer) exports cash balances from the bank portal and sends them to Kiran.
3. Working day 3: Kiran reconciles positions to the custodian statement. Any break above SGD 1,000 is raised with the custodian.
4. Working day 4: Arjun Mehta confirms the month as loaded. Until Arjun confirms, no figure is released.
5. Working day 5 to 8: Dev Sharma computes performance and Sameer Khan builds the report.

Known problem: the general ledger trial balance comes from the accounting system on working day 6 at the earliest, so the fee ratio is always the last figure to be ready.
