# Reconciliation procedure

Owner: Kiran Iyer. 1 June 2026.

Each month, total market value of positions in the custodian file is compared with the custodian statement total. A difference above SGD 1,000 is a break and the month stays not loaded until it is cleared. Duplicate rows in a file (the same security and date twice) are removed before the comparison and noted. Cash is reconciled to the Pier Bank statement by Rohan Das.
